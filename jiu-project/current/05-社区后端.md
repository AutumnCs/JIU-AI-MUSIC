# 社区后端

## 当前 MVP

社区数据由 Cloudflare D1 持久化：

- 帖子支持正文、最多 9 个图片地址和当前用户拥有的音乐任务。
- Feed 支持最新和热门排序，以及 cursor 分页。
- 帖子支持点赞、收藏、详情和通知。
- 评论支持父评论、嵌套回复、点赞和作者删除。
- 所有接口都要求游客 session，并在 D1 repository 层校验用户归属。

## Moderation 边界

当前只做正文长度、简单敏感词、图片数量和 URL 格式校验。面向儿童公开运营前，仍需要接入经确认的文本/图片审核、举报处理、审核记录和监护人策略。

## 发布约束

音乐附件必须来自当前用户自己的成功音乐任务。没有 `taskId` 的旧本地作品不会作为云端音乐附件，避免伪造或引用其他用户任务。

## 后续

- 将图片 URL 输入升级为 R2 上传接口。
- 将 `music_tasks` 附件替换为正式的 `music_works` 表。
- 在未成年人正式公开发布前补齐身份、监护人同意和审核策略。
