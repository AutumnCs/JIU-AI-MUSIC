# 社区后端

## 当前 MVP

社区数据已经从本地演示作品切换到 Neon/Hyperdrive API：

- 帖子支持正文、最多 9 个图片地址和一个当前用户拥有的音乐任务。
- Feed 支持最新和热门两种排序，以及 cursor 分页。
- 帖子支持点赞、收藏、详情和通知。
- 评论支持父评论、嵌套回复、评论点赞和作者/帖子作者删除。
- 所有接口都要求游客 session，并在数据库层校验用户归属。

## Moderation 边界

当前只做正文长度、简单敏感词拦截、图片数量和 URL 格式校验，数据库保留 `moderation_status` 字段。真正面向儿童公开运营前，需要接入经确认的文本/图片审核服务、举报处理、审核记录和监护人策略。

## 发布约束

音乐附件必须来自当前用户自己的已成功生成任务。旧的 localStorage 作品没有 `taskId` 时不会被当作云端音乐附件，避免用户伪造或引用其他用户的任务。
