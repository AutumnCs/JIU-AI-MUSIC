# Jiu 当前开发排期

> 基准日期：2026-08-10

## 当前基础能力

- 稳定 `POST /api/auth/guest`、`GET /api/me` 和 `POST /api/auth/logout`。
- 使用签名 HTTP-only cookie 管理 session。
- 通过 D1 持久化 `users`、`sessions`、音乐任务和社区数据。
- 保持本地草稿和临时状态的现有体验。

## 生产配置

1. 在 `wrangler.jsonc` 中维护 D1 的 `DB` 绑定和 R2 的 `MUSIC_BUCKET` 绑定。
2. 执行 `npx wrangler d1 migrations apply jiu-music-db --remote`。
3. 通过 `npx wrangler secret put AUTH_COOKIE_SECRET` 配置 session 密钥。
4. 构建并部署 Worker。
