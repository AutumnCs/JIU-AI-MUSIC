# Jiu 当前开发排期

> 基准日期：2026-08-03

## 当前下一里程碑：游客优先的后端身份
- 稳定 `POST /api/auth/guest` 的游客身份创建或恢复
- 稳定 `GET /api/me` 的当前用户查询和 `POST /api/auth/logout` 的会话退出
- 使用签名 HTTP-only cookie 管理会话
- 通过 PostgreSQL 持久化 `users` 和 `sessions`
- 保持本地草稿和临时状态的现有体验

这不是完整登录系统：先交付可恢复、可升级的游客身份后端，邮箱登录留到后续阶段。

## 阶段 2：把现有前端接到账号体系上
- 工坊草稿继续保留本地写入体验
- 作品、收藏、进度继续按当前用户 ID 归属
- 游客身份和本地草稿共存；云端同步另排期

## 阶段 3：Cloudflare 部署链路
- Workers
- Hyperdrive
- Neon PostgreSQL
- 生产环境只走数据库连接和 cookie 密钥

## 阶段 4：邮箱登录升级（后续）
- 先不急着做完整注册
- 后面再接邮箱验证和正式账号
- 游客数据可以平滑并入正式用户

## 阶段 5：作品和社区增强
- 云端保存作品
- 作品发布和分享
- 社区列表与互动

## 当前优先级
1. 先完成游客账号、会话和 PostgreSQL 后端这一下一里程碑
2. 再把前端的用户归属做完整
3. 再补 Cloudflare 的正式生产配置
4. 最后再推进邮箱登录

## 这版排期的判断标准
满足以下条件，就可以认为当前账号链路已经跑通：
- 用户首次打开应用可以自动拿到游客身份
- 关闭页面后再次打开，身份仍然可恢复
- 作品和进度能挂到同一身份上
- 生产环境不会再提示“没有后端”
