# Jiu 当前开发排期

> 基准日期：2026-08-03

## 阶段 1：先把游客账号跑通

- 游客身份创建
- 当前用户查询
- 退出登录
- Cookie 会话
- PostgreSQL 兼容存储

这一阶段已经是当前主线。

## 阶段 2：把现有前端接到账号体系上

- 工坊草稿继续保留本地写入体验
- 作品、收藏、进度逐步转成用户归属
- 游客身份和本地草稿共存

## 阶段 3：阿里云部署链路

- 函数计算 Web 函数
- RDS PostgreSQL
- 生产环境只走 `DATABASE_URL`
- 不再依赖本地文件回退

## 阶段 4：邮箱登录

- 先不急着做完整注册
- 后面再接邮箱验证和正式账号
- 游客数据可以平滑并入正式用户

## 阶段 5：作品和社区增强

- 云端保存作品
- 作品发布和分享
- 社区列表与互动

## 当前优先级

1. 先稳定游客账号和会话
2. 再把前端的用户归属做完整
3. 再补阿里云部署的正式生产配置
4. 最后再推进邮箱登录

## 这版排期的判断标准

满足以下条件，就可以认为当前账号链路已经跑通：

- 用户首次打开应用可以自动拿到游客身份
- 关闭页面后再次打开，身份仍然可恢复
- 作品和进度可以挂到同一身份上
- 生产环境不会再提示“没有后端”
