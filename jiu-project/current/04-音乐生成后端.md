# 音乐生成后端

## 当前链路

工坊请求按以下顺序运行：

1. 前端使用游客 session 调用 `POST /api/music/create`。
2. Worker 校验当前用户和输入参数。
3. Worker 使用 Volcengine Imagination API 创建任务，并把任务写入 Neon 的 `music_tasks` 表。
4. 前端轮询 `GET /api/music/status/{taskId}`。
5. 生成成功后，如果配置了 R2，Worker 把音频保存到 `MUSIC_BUCKET`，否则返回火山临时 URL。
6. 播放 R2 音频时调用 `GET /api/music/audio/{taskId}`，接口再次校验任务所属用户。

## 配置

本地可以不配置密钥，工坊会回退到本地样例音频。真实生成需要通过 Cloudflare/Wrangler secrets 配置：

- `VOLC_ACCESS_KEY`
- `VOLC_SECRET_KEY`
- `VOLC_SESSION_TOKEN`（使用临时凭证时配置）

`jiu-app/wrangler.jsonc` 中的 `MUSIC_BUCKET` 需要指向已存在的 R2 bucket。数据库需要先执行 `jiu-app/lib/server/schema.sql`，其中包含 `music_tasks` 表。

## 安全边界

- 所有任务读写都带 `user_id` 条件。
- 不把火山密钥放进请求体、日志或响应。
- `.dev.vars`、`.neon`、构建输出和本地状态文件不提交。
- R2 音频使用私有接口，不提供未经鉴权的公共 taskId 下载。

## 接口字段

创建接口支持 `track: vocal | instrumental`。人声支持 `lyrics` 或 `prompt`，伴奏支持 `text`，两者都支持 `genre`、`mood`、`duration` 和最多两种 `instruments`。

无密钥或供应商不可用时，前端仍保留 local provider，方便开发和 UI 验证；生产环境配置完成后会优先走真实生成接口。
