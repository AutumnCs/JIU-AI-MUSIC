# Jiu 当前技术架构

> 基准日期：2026-08-10

## 架构目标

以游客优先的服务端身份和会话为基础，保留前端本地草稿体验，并让音乐任务与社区数据可按用户归属持久化。

## 当前分层

### 前端层

- Next.js App Router 与 React 19。
- Zustand 和 `localStorage` 保存草稿、临时 UI 状态及本地兜底数据。

### 服务端层

- Cloudflare Workers 承载 Next.js route handlers。
- `POST /api/auth/guest`、`GET /api/me`、`POST /api/auth/logout` 管理游客身份和 session。
- `lib/server/db.ts` 通过 D1 repositories 提供 auth、music 和 community facade。

### 存储层

- Cloudflare D1 保存 `users`、`sessions`、`music_tasks` 和社区关系数据。
- Cloudflare R2 保存音乐音频。
- `migrations/0001_init.sql` 管理可重复执行的数据库结构。

## 部署与配置

- `wrangler.jsonc` 绑定 `DB` 和 `MUSIC_BUCKET`。
- `AUTH_COOKIE_SECRET` 作为 Worker secret 配置。
- 部署前执行 `npx wrangler d1 migrations apply jiu-music-db --remote`。

## 运行边界

- 邮箱登录、用户资料编辑与完整云同步仍是后续工作。
- 服务端负责身份、会话和业务数据归属；前端本地草稿体验保持不变。
