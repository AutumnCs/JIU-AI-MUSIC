# Jiu 当前项目总览

> 基准日期：2026-08-10

Jiu 是面向儿童音乐启蒙与 AI 创作的移动优先 Web App，包含 Collection、Academy、Workshop 和 Community 四个产品模块。

## 当前运行架构

- 前端工程位于 `jiu-app/`，部署到 Cloudflare Workers。
- D1 持久化用户、会话、音乐任务和社区数据。
- R2 保存音乐音频。
- `migrations/0001_init.sql` 是数据库结构的唯一来源。
- 游客 session、当前用户查询和退出登录均由服务端 API 提供。

## 当前开发方向

1. 稳定游客账号、session 和 D1 数据存储。
2. 完善前端用户归属和邮箱登录升级路径。
3. 持续完善作品发布、分享、社区和持久化能力。

## 当前环境配置

- `AUTH_COOKIE_SECRET`：签名 HTTP-only session cookie；生产环境通过 Wrangler secret 设置。
- D1 和 R2 绑定在 `jiu-app/wrangler.jsonc` 中管理。

## 数据库操作

```bash
npx wrangler d1 migrations apply jiu-music-db --local
npx wrangler d1 migrations apply jiu-music-db --remote
```
