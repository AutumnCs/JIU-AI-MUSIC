# Jiu 当前项目总览

> 基准日期：2026-08-04

## 这是什么项目

Jiu 是一个面向儿童音乐启蒙与 AI 创作的移动优先 Web App。当前产品仍然围绕四个核心动作展开：

- 学
- 唱
- 创
- 收藏

## 当前模块

- `Collection` 鸟类图鉴
- `Academy` 学院关卡
- `Workshop` 工坊录音与 AI 生成
- `Community` 作品社区
- 全局导航和首次引导

## 当前状态

- 前端主工程仍在 `jiu-app/`
- 公网站点已经部署到 Cloudflare Workers
- 公开访问域名当前先使用 `workers.dev`
- 后端基础链路已经接入 Cloudflare Workers + Hyperdrive + Neon PostgreSQL
- 游客 session / 当前用户查询 / 退出登录 已经有基础 API
- `workshop` 和 `community` 已经对齐到共享 workshop 底座，但业务级数据库后端还要继续补

## 现在可以怎么理解这个项目

- 不是“没有后端”
- 也还不是“完整账号系统”
- 现在是“基础后端已上线，业务后端继续补齐”的阶段

## 当前产品定位

- 仍然是移动优先
- 仍然适合手机浏览器直接访问
- 仍然强调儿童友好、步骤少、反馈强
- 但现在已经有可持续扩展的账号与数据骨架

## 当前开发方向

1. 先把游客账号、session 和数据库稳定住
2. 再把前端用户归属做完整
3. 再补邮箱登录
4. 最后再完善作品发布、分享、社区和持久化能力

## 当前关键环境变量

- `DATABASE_URL`
- `AUTH_COOKIE_SECRET`

Cloudflare 线上部署时，`DATABASE_URL` 主要对应 Neon 连接信息，或由 Hyperdrive 转接 Neon。
