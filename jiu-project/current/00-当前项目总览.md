# Jiu 当前项目总览

> 基准日期：2026-08-03

## 这是什么项目

Jiu 是一个面向儿童音乐启蒙与 AI 创作的移动优先 Web App，核心体验围绕四件事展开：

- 学
- 唱
- 录
- 收集

## 当前模块

- `Collection` 鸟类图鉴
- `Academy` 学院关卡
- `Workshop` 工坊录音与 AI 生成
- `Community` 作品社区
- 全局导航和首次引导

## 当前仓库状态

- 前端主工程仍在 `jiu-app/`
- 现有状态大体仍以本地存储驱动，适合快速启动和离线草稿
- 游客账号体系和服务端会话已经补上，后端边界不再是空的
- 当前主线已经切到 **Cloudflare Workers + Hyperdrive + Neon Free Postgres**

## 当前后端结论

现在项目里已经有一个最小但完整的后端骨架：

- 游客创建
- 当前用户查询
- 退出登录
- PostgreSQL 兼容存储

这意味着：

- 不再是“没有后端”的阶段
- 也还不是完整登录系统
- 下一步是把 workshop / community 的数据归属继续接到这个账号体系上

## 当前产品定位

- 仍然是移动优先
- 仍然适合手机浏览器直接访问
- 仍然以儿童友好、步骤少、反馈强为重点
- 但现在已经有了可升级的账号基础

## 当前开发方向

1. 先把游客身份和会话链路稳定住
2. 再把前端的用户归属做完整
3. 再补邮箱登录升级
4. 最后再考虑更完整的发布、分享、社区和持久化能力

## 当前关键环境

- `DATABASE_URL`
- `AUTH_COOKIE_SECRET`

Cloudflare 线上部署时，`DATABASE_URL` 主要对应 Neon 或 Hyperdrive 提供的 PostgreSQL 连接信息。
