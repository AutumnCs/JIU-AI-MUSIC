# 后端与登录方案

> 当前版本：Cloudflare D1 主线版
> 基准日期：2026-08-10

## 目标

先跑通游客身份、session 和数据归属的最小闭环；后续可在同一用户体系上升级邮箱登录，不必重做前端。

## 当前实现

- `lib/server/auth.ts` 管理游客创建、当前用户查询和退出登录。
- `lib/server/db.ts` 委托 D1 repositories 处理身份、音乐任务和社区数据。
- session 写入签名的 HTTP-only cookie，浏览器端不直接读取 cookie。
- `users` 预留 `guest` 与 `email` 两种用户类型。

## 当前部署方案

采用 **Cloudflare Workers + D1 + R2**：

- Workers 运行 API 和应用服务端代码。
- D1 保存关系数据。
- R2 保存音乐音频。

部署时先执行：

```bash
npx wrangler d1 migrations apply jiu-music-db --remote
npx wrangler secret put AUTH_COOKIE_SECRET
```

然后构建并部署 Worker。`wrangler.jsonc` 中的 `DB` 与 `MUSIC_BUCKET` 是运行时绑定。

## 最小接口

- `POST /api/auth/guest`：创建或恢复游客身份。
- `GET /api/me`：查询当前身份。
- `POST /api/auth/logout`：撤销当前 session。

## 后续边界

- 更完整的作品同步、发布和分享。
