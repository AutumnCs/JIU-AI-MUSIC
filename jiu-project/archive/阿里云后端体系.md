# 阿里云后端体系

> 这份文档是归档参考，不是当前主线。
> 当前主线已经切到 Cloudflare Workers + Hyperdrive + Neon。

## 1. 这套体系是干什么的

阿里云体系适合在你想要更传统的云服务时回切使用：

- 函数计算 FC Web 函数负责 API
- RDS PostgreSQL 负责用户、会话和业务数据
- OSS 负责音频、图片、导出文件

## 2. 适合什么时候回切

- 你需要更传统的国内云托管
- 你想把数据库、函数和对象存储都放在阿里云
- 你需要更贴近国内项目交付场景的部署方式

## 3. 回切时的最小配置

### 函数计算

- 部署 Next.js 生成的服务端入口
- 配置 Node.js 运行时
- 配置 `DATABASE_URL`
- 配置 `AUTH_COOKIE_SECRET`

### RDS PostgreSQL

- 创建 PostgreSQL 实例
- 执行 `jiu-app/lib/server/schema.sql`
- 保证 `users` 和 `sessions` 表存在

### OSS

- 后面如果需要存音频或图片，再单独接入
- 现在不影响游客账号主链路

## 4. 这套体系保留的价值

- 以后如果 Cloudflare 成本或限制不合适，可以快速回切
- 数据模型还是关系型，迁移成本较低
- 和现在的账号设计不冲突

## 5. 结论

这份文档只作为“以后改回阿里云”的参考，不影响当前 Cloudflare 主线。
